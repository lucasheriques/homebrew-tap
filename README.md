# Homebrew tap

```sh
brew install lucasheriques/tap/pgram
```

Prebuilt binaries for macOS and Linux, on ARM and Intel, from
[pgram releases](https://github.com/lucasheriques/pgram/releases).
The daily update workflow uses published SHA-256 checksums and can also be run
manually with `gh workflow run update.yml --repo lucasheriques/homebrew-tap`.

This tap and pgram do not send usage telemetry.
